隐私政策

适用于 minichat.astras.cc

MiniChat 是一个开源的小型实时聊天站点。这份说明告诉你：我们收集什么、用它做什么、以及你可以怎么删掉它。

一、我们收集什么

  • 账号信息：你注册时使用的邮箱地址；如果你用微软或 GitHub 账号登录，我们从该平台获取你的邮箱、显示名称和头像地址。
  • 你主动填写的内容：显示昵称、个性标签、头像。
  • 聊天内容：你在公共聊天、群聊、私聊中发送的消息，以及你上传的图片/文件。
  • 为了维持服务运行必需的技术信息：登录会话凭据、大致在线状态。

我们不收集：你的密码（第三方登录时代码里没有任何密码字段）、通讯录、位置、设备标识符，也不投放任何广告或做用户画像。

二、怎么用这些信息

  • 让你能登录、发消息、看到别人发的消息；
  • 维护聊天室的基本秩序（例如频率限制、群管理操作）；
  • 仅此而已。不会用于广告、不会出售、不会提供给第三方做营销。

三、数据存在哪里

数据托管在 Supabase（PostgreSQL 数据库 + 对象存储）。生产环境通过行级安全策略（RLS）限制访问：只有会话参与者能读到该会话的消息，未登录用户读不到任何消息。头像与附件存放在对象存储中，按需生成可访问链接。

四、你能做什么

  • 修改：昵称、个性标签、头像都能在设置里随时改。
  • 删除账号：设置里有「注销账号」。注销后你的账号与资料会被删除，你发过的消息会被匿名化为「已注销用户」，聊天记录本身保留（以免破坏他人的会话上下文）。
  • 拉黑：你可以把某人加入黑名单，之后你们互相不可见、无法互发好友请求、也无法私聊。

五、第三方登录

使用微软或 GitHub 登录时，你会在对方的授权页面上确认权限。MiniChat 只申请最基本的范围（读取邮箱与公开资料），不会获得你的密码，也无法代表你在该平台上做任何其他操作。

六、本政策可能的变更

这是个人维护的开源项目，政策如有调整会直接更新本页，并修改页脚下的更新日期。
